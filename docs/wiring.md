# การต่อวงจร

```
ESP32 DevKit                 Breadboard
┌──────────────┐
│        GPIO23├──────[ 220Ω ]──────►|──────┐
│              │                   LED      │
│              │            (ขายาว)  (ขาสั้น) │
│           GND├────────────────────────────┘
│              │
│     USB ─────┼──── คอมพิวเตอร์ (ไฟเลี้ยง + Serial)
└──────────────┘
```

| ESP32 | ต่อไปที่ |
|---|---|
| GPIO 23 | ตัวต้านทาน 220Ω → ขายาว (Anode +) ของ LED |
| GND | ขาสั้น (Cathode −) ของ LED |
| USB | คอมพิวเตอร์ |

- LED บนบอร์ด (GPIO 2) จะติด/ดับตามไปด้วย ใช้ทดสอบได้แม้ยังไม่ต่อ LED ภายนอก
- ถ้าต้องการเปลี่ยนขา แก้ `LED_PIN` ใน `esp32/led_control/led_control.ino`
- กระแส LED ≈ (3.3 − 2.0) / 220 ≈ 6 mA ปลอดภัยสำหรับขา GPIO ของ ESP32
